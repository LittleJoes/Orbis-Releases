# Orbis desktop releases

Official macOS and Windows installers and update files for [Orbis](https://c-o.pw).

This repository contains distribution files only. The application source is maintained separately in a private repository.

No desktop installer has been published yet. Use [Orbis in your browser](https://c-o.pw) while the signed installers complete release testing.

Published stable releases use `desktop-vMAJOR.MINOR.PATCH` tags. The desktop app checks this repository for updates; downloading and restarting to install remain your choice. Do not install assets from drafts or unrelated repositories.

For help, contact [Orbis support](https://c-o.pw/support). Orbis is operated by Rarkaz LTD.
